How technical do I need to be?

You need to be comfortable with a terminal — opening a command line, running scripts, editing text files. If you've ever SSHed into a server or run a cron job, you're ready. If not, Chapter 1 walks you through environment setup from scratch. This isn't for complete beginners to computers, but it's not for senior engineers only either. It's for builders.

Jared's full stack of 25+ agents runs for $3–5/day. That's roughly $100–150/month in API costs.
